Booth space and map visibility are two different steps. Booth space comes first. Listing upgrades come after you are on the grounds.

Before You Apply

The fastest way to create confusion is to mix booth rental with map listing upgrades. Use the vendor application if you still need a space. Use listing tools later when your booth is already established.

Need booth space?

Start with the vendor application and basic market rules. That is the path for getting onto the grounds as a vendor.

Already have booth space?

Once your location is set, come back to the listing side to improve how shoppers discover your booth in the map experience.

Basic Vendor Path

Most vendors are moving through one of these three situations.
Step One

Apply for Space

Booth first / listing later

If you do not have a booth yet, start with the application and rules process before thinking about upgrades.

  • Review the application process
  • Understand market expectations
  • Get your booth situation handled first
Step Two

Claim Your Listing

Map ready / after approval

Once you already have space, claim your booth listing so your booth can be discovered more easily by shoppers online.

  • Connect your booth to the map
  • Improve findability for shoppers
  • Prepare for richer listing options
Step Three

Upgrade Visibility

After setup / optional

Photos, categories, links, and richer listing tools make sense after the booth itself is already in place.

  • Map listing upgrades
  • More shopper discovery
  • Richer digital presence

What Vendors Need to Know

Space comes before listing polish

Do not send a vendor to the listing claim path if they still need booth approval or rental information first.

Shoppers use the map differently than vendors use applications

The booth application solves space. The listing tools solve discoverability and better shopper guidance.

Use the right page for the right job

This page is for booth-rental direction. The listing page is for map presence, upgrades, and claim flow.

Keep the handoff clear

Once a vendor has a booth, the next useful handoff is the map listing page, not another round of rental instructions.

Ready to Sell?

If you need your booth, start with the application. If your booth already exists and you want more visibility, use the listing-info path next.
